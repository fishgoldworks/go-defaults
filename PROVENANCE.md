# Source provenance

This standalone package was extracted from `Apps/post-share/src/libs/go-js` on 2026-09-14. The runtime is identical across the Post Share and Match Offer client copies and the corresponding read-only FMG source; the existing Jest behavior tests were carried with it.

The canonical helper files contain no license header, Post Share has no root license, and its server copyright notice does not grant a license. The older, distinct `Libs/go.js` project does not contain these helpers; its package metadata says MIT while its LICENSE file says CC BY-NC-ND 3.0 NZ. This package therefore does not borrow either license and remains `UNLICENSED` pending an explicit owner decision.
